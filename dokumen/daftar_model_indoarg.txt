2. PENJELASAN FORMAT GGUF & ARTI KUANTISASI (Q4_K_M DAN TANGGA EKSPERIMEN B)
================================================================================
- Format File      : GGUF v3 (GGML Unified Format), standar biner llama.cpp yang
                     menyimpan bobot tensor, kosakata tokenizer, hyperparameter
                     arsitektur, dan Jinja chat template dalam satu file.
- Kuantisasi Utama : Q4_K_M (kode general.file_type = 15, MOSTLY_Q4_K_M).
  Apa artinya "Q4_K_M"?
  * Q4  = Mayoritas bobot matriks linear dikuantisasi ke presisi 4-bit (~4,5-4,8
          bit efektif per parameter termasuk faktor skala blok).
  * K   = K-Quant (super-block 256 bobot dengan sub-block scale terkuantisasi),
          jauh lebih akurat daripada Q4_0 klasik.
  * M   = Medium (campuran presisi adaptif): layer yang sensitif terhadap error
          (seperti attention_v, feed_forward_down, output head, embedding)
          dinaikkan ke Q5_K, Q6_K, atau Q8_0, sedangkan bobot normalisasi
          (RMSNorm / bias / scale) dipertahankan di F32 (32-bit penuh).
  * imatrix = Importance Matrix (kalibrasi aktivasi pada teks referensi agar
          error kuantisasi minimal pada arah bobot yang paling berpengaruh).

- Tangga Kuantisasi Eksperimen B (khusus M1 dan M3):
  1. BF16   (code 32) : Brain Float 16-bit (tanpa kuantisasi integer; baseline atas)
  2. Q8_0   (code 7)  : 8-bit integer blok standar (~hampir lossless vs BF16)
  3. Q6_K   (code 18) : 6-bit K-quant (presisi tinggi)
  4. Q4_K_M (code 15) : 4-bit K-quant medium (titik operasi utama laptop 6 GB VRAM)
  5. Q3_K_M (code 12) : 3-bit K-quant medium (kompresi agresif untuk uji degradasi)
