Tahap 1 (Analisis dan Normalisasi):
Analisis permintaan pengguna secara singkat sebelum mengeluarkan JSON (maksimal 5 baris).
1. Pilih tepat satu nama tool target yang sesuai dengan permintaan pengguna; hanya tulis NO_CALL jika permintaan benar-benar tidak sesuai dengan tool mana pun.
2. Tuliskan HANYA argumen milik satu tool target terpilih tersebut dalam bentuk kanoniknya (waktu ISO-8601+07:00, tanggal YYYY-MM-DD, nominal rupiah bulat, kode wilayah XX.XX, kode stasiun KRL, satuan gram/menit, nilai enum baku). Jangan menuliskan argumen dari tool lain.
3. Jangan keluarkan JSON final dulu; cukup daftar ringkas nama tool dan nilai argumen kanoniknya.
